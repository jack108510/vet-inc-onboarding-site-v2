## Variant: Editorial evidence

### Design stance
A calm, credible research-journal direction. It leads with the question, makes FeeWatch feel thoughtful, and gives the free-analysis CTA room to breathe.

### Key choices
- Original visual system, using the current Vet INC logo and credible live-product boundaries.
- Interactive conversion state: request modal/drawer.
- Responsive, standalone HTML.

### Trade-offs
- These are exploration artifacts, not production pages.
